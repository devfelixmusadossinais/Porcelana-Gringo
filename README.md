# Korean Silk Method — paginas (demo)

Tres paginas estaticas, uma por pasta. No Netlify, crie um site por pasta
e use **Base directory** = nome da pasta (ex.: `Laurakim.of`). O `netlify.toml`
de cada pasta ja publica `site/`.

- `Laurakim.of/`
- `nora_wong/`
- `hannah_soojin/`

Antes de ir ao ar de verdade: trocar prints/depoimentos, numeros de exemplo,
links de checkout (`#CHECKOUT_*`, `#APP_URL`) e revisar precos e avisos legais.
